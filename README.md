# ICSE27-SEIS-GenAI-SE-Academics --  Replication Package

This repository contains supporting materials for the study, including the survey instrument, the qualitative codebook and descriptive statistics, and the figures used to report results for our paper: **Perceived Implications of GenAI on Software Engineering Academics' Well-Being**

## Contents

| Material | Description |
| --- | --- |
| **Survey (PDF)** | The questionnaire administered to respondents, including the survey questions and response options. |
| **Codebook (PDF)** | The topics identified from the open-ended responses, their descriptions, their organization into higher-level themes, and the accompanying summary statistics. |
| **Grpahs** | Graphs used to present the quantitative findings for Demographics, RQ1 and RQ2. |

## How to use this package

1. Consult the **survey PDF** for the wording of the questions and available response options.
2. Refer to the **codebook PDF** for topic descriptions and the theme structure used to analyze the open-ended responses. The accompanying statistics summarize the reported results.
3. View the **Graphs.pdf** alongside the corresponding results section in the paper.
4. Download the **Graphs.xlsx** if you want to reproduce the graphs.



## Notes

The materials are intended to support transparency and interpretation of the reported findings. The package documents the survey, coding framework, statistics, and RQ1 visualizations; it does not, by itself, imply that individual-level survey responses or analysis scripts are included.

## Citation

When using these materials, please cite the accompanying research paper.
